## Agentic Prompt — Products Collection Seed + Referential Integrity

### Context

1. Study the home page and the product list/filter pages to understand how products are listed and filtered. ([fanproselect.kdk-mea.com][1])
2. The product catalog exposes a set of product model codes and category/subcategory structures used in the UI’s filters (e.g., product lists require selecting Region + Country + Category + Subcategory first). ([fanproselect.kdk-mea.com][1])

**Do not create any application pages or features beyond database seeding and structure.**

## Acceptance Criteria (Agentic System)

### A. Extract Product List

**Given** the public product list and filter UI
**When** the agent inspects the catalogue content
**Then** it must extract all **distinct product model codes** that appear on or implied by the product list pages:

Examples include items shown under *Ventilation Fan* category such as `10BAQ1`, `10EGKB`, `10EGSB`, `15AAQ1`, `17CUH`, `20AUA`, `20AUH`, etc. ([kdk-mea.com][2])

**Actionable extraction task**

* Derive a list of unique model codes from the product categories visible within `ventilation fan` and similar segments.
* Do not add unrelated products outside the fans/ventilation domain.

This list will be used for initial seeding.

---

### B. Create Seed File

**Goal**: Populate `lib/db/products/seed.ts` with an **empty seed array template** that will later be filled with actual record objects extracted in step A.

**Requirements**

1. Create the file (if missing): `lib/db/products/seed.ts`.
2. Export a constant named `seedProducts`:

```ts
export const seedProducts: ProductInsert[] = [];
```

3. Do **not populate** the array with data now — it must remain empty but ready for future entries.

4. Ensure the file is syntactically correct and imports/inferences are available for `ProductInsert` type.

---

### C. Referential Integrity Check (Product ↔ Regions/Countries/Categories/Subcategories)

**Given**

* Existing seed data in `lib/db/seed.ts` for `regions`, `countries`, `categories`, `subcategories`.

**When**

* A product seed entry exists (future populated records reference codes)

**Then**

1. The agent must enforce that every product record’s:

   * `categoryCode` matches exactly a code present in the `categories` collection seed.
   * `subcategoryCode` matches exactly a code present in the `subcategories` collection seed.
   * Each `marketSpecs.regionCode` and `marketSpecs.countryKey` (or other relation key) must correspond to existing `regions` and `countries`.

2. Implement automated checks in the seeding pipeline:

   * Before inserting a product, validate that referenced category and subcategory codes exist.
   * Validate region and country codes/keys exist in the corresponding collections.
   * If any mismatch is found, throw a clear error indicating the invalid cross-reference.

3. Do **not** assume referential integrity by default — the seeder must verify every cross-reference explicitly.

---

### D. Zod Schemas + TypeScript

**Given** the products collection model

**When** building schemas

**Then**

1. Create a Zod validation schema for `ProductInsert`:

   * Must mirror the `products` collection structure.
   * Must validate all fields including nested arrays (`marketSpecs`, `pqCurves`).
   * Include `.superRefine()` logic to assert:

     * `airVolume.min <= airVolume.max`
     * `staticPressure.min <= staticPressure.max`

2. Infer TypeScript types using:

   ```ts
   export type ProductInsert = z.infer<typeof ProductInsertSchema>;
   ```

3. Use these types in:

   * seed file (`seedProducts: ProductInsert[]`)
   * seeding logic
   * referential integrity checks

---

### E. Index and Schema Enforcement

**Given** the products collection

**When** the bootstrap runs

**Then**

1. Ensure the following indexes exist:

   * Unique index on `{ modelCode: 1 }`
   * Unique index on `{ slug: 1 }`
   * Optional multi-field index on `{ categoryCode: 1, subcategoryCode: 1 }`
   * Index on `{ "marketSpecs.regionCode": 1, "marketSpecs.countryKey": 1 }`

2. These indexes must be created programmatically in seeding/bootstrap logic (not manually).
